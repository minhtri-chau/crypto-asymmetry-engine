# v8.9.2 deployment

v8.9.2 adds an explainable Current Setup breakdown and a Research price chart.

1. Push v8.9.2 to GitHub `main` and let Vercel deploy it.
2. No Supabase SQL migration is required.
3. No Supabase Edge Function redeploy is required.
4. No Cron change is required.
5. No new environment variable or package dependency is required.

Smoke tests:
- Open AAVE Research and confirm Current Setup still matches AAVE in Scanner.
- Confirm the Setup breakdown shows Liquidity, Market quality / size, Supply / dilution, Price confirmation, Fundamentals and Extension penalty.
- Confirm each criterion shows both an explanation and its high-score rule.
- Confirm the displayed raw-points denominator matches the Scanner normalization semantics.
- Confirm the price chart loads and `1M / 3M / 6M / 1Y` changes the visible history without a new page/API refresh.
- Confirm Price, 50D MA and 200D MA render on the 1Y chart.
- Confirm Entry/Position Signal behavior is unchanged.
