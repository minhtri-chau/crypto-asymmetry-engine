# v8.9.5 deployment

v8.9.5 adds observational structural market timing to the Scanner and Research detail page.

## 1. Run the Supabase migration
Run `V8.9.5-MIGRATION.sql` in the Supabase SQL Editor. It only adds three nullable Signal Journal columns.

## 2. Deploy
Push the release files to GitHub `main` and let Vercel deploy.

No Edge Function, Cron, environment-variable, dependency, or setup-v3 scoring change is required.

## Smoke test
1. Scanner shows a **Structure** column for enriched high-priority candidates. The server caps structural candle enrichment at 40 assets per refresh to avoid turning the Scanner into an API-request furnace.
2. Structure stages can include `BELOW RESISTANCE`, `EARLY STRUCTURE`, `NEAR BREAKOUT`, `BREAKOUT ATTEMPT`, `CONFIRMED BREAKOUT`, `RETEST / HOLD`, `SUPPORT HELD`, and `EXTENDED`.
3. Research detail shows **Structural market state** with resistance, distance, 200D EMA and completed-week confirmation.
4. Research detail shows **BTC downside sensitivity**, calculated from historical non-overlapping 7-day windows where BTC fell at least 5%.
5. Scanner displays its server refresh timestamp.
6. Setup Evidence remains `setup-v3`; structural evidence is observational and does not add hidden points.
7. Promotion Review must contain `</button>)}` and never the invalid `</button>})}` closure.
