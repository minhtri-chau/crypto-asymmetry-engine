first-class CONFLICTED evidence. It adds NO Vercel function.

Deployment:
1. Run V10.1-MIGRATION.sql and append it to current supabase.sql.
2. Apply ENDPOINT-PATCH.md to CURRENT api/catalyst-intelligence.js.
3. Apply FRONTEND-PATCH.md to CURRENT src/main.jsx.
4. Keep catalyst-intelligence maxDuration at 300 seconds.
5. Build + lint and deploy.
6. Retry TIA once.

TIA acceptance:

- Repair performs no web search and adds no facts.
- If both attempts fail, previous stored intelligence remains untouched and UI shows a precise failure code.
- Every saved event still has a real HTTPS source.
- Bad dates -> unknown; impossible percentages -> blank.
- Conflicting schedules -> CONFLICTED rather than silently resolved.
