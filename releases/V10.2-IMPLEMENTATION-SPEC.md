# v10.2 Price Expectation Engine v1

Implement as a NEW Supabase Edge Function `price-expectation`; no new Vercel function.

## Source-of-truth
Patch CURRENT GitHub main. Reuse the corrected v9.7 `similarity-engine` formulas for today's vector and historical distance, including:
- today's state from fresh `historical_price_daily` Coinbase closes, never newest replay point
- 7D return, 30D return, RSI14, price vs MA50, price vs MA200, 90D drawdown, BTC-relative 30D
- gap-free BTC Coinbase daily retrieval behavior
- only outcomes fully matured by the as-of date

## v10.2 calculation
For each non-archived researched asset and horizon 7/30/90:
1. Rank this asset's historical replay observations by v9.7 distance to TODAY.
2. Keep up to 40 nearest candidates with a matured outcome for that horizon.
3. Weight each candidate by `1 / (0.15 + distance)^2`.
4. Calculate weighted q25, weighted median, weighted q75 of asset_return_pct.
5. Calculate weighted median BTC-relative return.
6. Convert return references to dollars:
   current_price * (1 + return_pct/100).
7. Count non-overlapping independent periods for the horizon.
8. Persist horizon JSON with:
   state, confidence, n, independent_periods, median_distance,
   q25_return_pct, central_return_pct, q75_return_pct,
   median_btc_relative_pct, downside_price, central_price, upside_price,
   method, and the top 10 neighbor dates/distances/outcomes.

## State
- insufficient evidence if no usable median
- CONSTRUCTIVE only if q25 > 0
- CAUTIONARY only if q75 < 0
- SLIGHTLY_CONSTRUCTIVE if median >= +5%
- SLIGHTLY_CAUTIONARY if median <= -5%
- otherwise MIXED

## Confidence
Never emit HIGH in v10.2.
- INSUFFICIENT if n < 15 or independent_periods < 3
- MODERATE only if independent_periods >= 8, median_distance <= 0.65, and IQR <= 30 percentage points
- otherwise LOW

## Hard invariants
- ASSET-SPECIFIC ONLY. Never average cross-asset calibration into price expectation.
- No fundamentals, regime, catalysts, qualitative research or AI projected backward.
- No current non-price evidence shifts the historical distribution.
- No point forecast or probability language.
- No deterministic posture/Setup/Thesis changes.
- v9.7 remains context-only.
- hard risk/profit rules remain authoritative.
