# v10.4 — Remove from Research

The Research page now has Active Research and Watchlist only. Remove replaces Archive. Confirming removal hides a non-owned coin from Research and the research dashboard, releases its tracked Scanner state, and stops future background research. Scanner can explicitly add it again.

Removal remains a user decision; a removal-review or exit-review signal never removes or sells a coin automatically. Owned assets cannot be removed. The write checks current ownership on both the research record and saved plan, and requires the research record to remain unowned when saving. Failure stays visible in the UI.

The existing `archived` database stage is retained internally as an inactive marker. Existing non-owned archived coins disappear from the visible list. Legacy archived owned coins remain accessible in Active Research and can be restored with Research. Retaining records preserves purchase, evaluation and validation history and prevents curated seeding on another browser from recreating removed assets. The existing workers already skip the inactive stage. Historical `archive_candidate` status IDs stay compatible with scoring and stored evaluations; the Research UI calls this Removal review.

Deployment: push to GitHub main; Vercel builds the frontend. No SQL migration, Supabase function redeploy, cron or dependency changes are required. No API functions were added (10 existing API files).

Validation: `node --test tests/research-lifecycle.test.mjs` and `npm run build`.

Live acceptance: remove an unowned coin, reload and verify it stays absent; find it in Scanner and Add to Research; verify an owned coin cannot be removed. No live user records were changed during automated validation.
