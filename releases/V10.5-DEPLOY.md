# v10.5 — Drag to measure price changes

On each Research coin's price chart, press and drag between daily price points. The chart shades the selected interval, marks both endpoints and shows percent change, dollar change, endpoint dates/prices and elapsed days. Release retains the measurement. Click a single point, Clear, or Escape dismisses it. Changing range, coin or historical data resets it. Hover inspection and 50D/200D averages remain available.

The first point clicked is the baseline: dragging $100 to $125 shows +25%; dragging $125 to $100 shows -20%. Elapsed time is absolute. Measurements use recorded daily prices, not interpolated intraday prices. Touch/pen dragging uses the same pointer events. Screen-to-SVG conversion accounts for responsive scaling and letterboxing.

Deployment: copy the supplied files into the existing v10.4 repository, keeping relative paths, then commit and push. Vercel builds the frontend. No SQL, Supabase worker, dependency or API changes are required.

Checks: `node tests/chart-measurement.test.mjs` and `npm run build`. The ZIP includes actual changed source, tests and a patch against the local v10.4 implementation.
