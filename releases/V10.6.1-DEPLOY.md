# v10.6.1 — Optional AI and independent refresh steps

**Refresh Research with AI** attempts all four steps, in order, even when one or more fail. **Refresh Research without AI** runs only the quantitative evaluation, skipping all AI-powered sourced research, catalyst research and assessment calls. Previously stored sourced research, events and AI assessments remain visible. Completed results remain saved and failed steps retain their individual error messages. The overall result reports failure if any step failed, without preventing other steps from completing.

Later steps use freshly saved quantitative and qualitative results when available. If those refreshes fail, they use the existing asset, latest evaluation and stored sourced research, including its original timestamp. Missing evidence stays missing. The final AI step reloads available event records even if the event refresh failed.

## Deploy

Extract this zip into your existing v10.6 repository, preserving paths, then commit and push as usual. Wait for Vercel to show Ready and reload the dashboard. No Supabase Edge Function redeployment, environment changes or SQL migration is needed for this patch.
