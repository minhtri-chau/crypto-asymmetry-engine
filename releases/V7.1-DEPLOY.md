# v7.1 deployment
Push v7.1 to GitHub main and preserve the existing package-lock.json.

In Vercel -> Project -> Settings -> Environment Variables, add:
COINGECKO_DEMO_API_KEY = your CoinGecko Demo API key

Do not prefix it with VITE_. Redeploy Production after adding it.

No Supabase SQL, Edge Function, Cron, or secret changes are required.
After deploy, Scanner should show `Early-asymmetry discovery` and `CoinGecko key ON`.
