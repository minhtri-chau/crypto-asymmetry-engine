# v8.4 deployment

1. Push v8.4 to GitHub `main`, preserving the genuine current `package-lock.json`.
2. Run the updated `supabase.sql`. v8.4 adds only `research_assets.research_origin` and is safe to re-run.
3. No Edge Function redeploy is required.
4. No Cron changes are required.
5. Sign out/in or refresh while signed in. The app will seed the original nine into the unified Research pipeline once for that account.

Smoke test:
- Scanner contains the full eligible Coinbase universe and no longer has a separate Deep research & watchlist table.
- Search/scroll the Scanner and confirm original assets such as AAVE can appear with a current Research Priority when they clear the market-cap/liquidity screen.
- Research contains the original nine plus existing promoted assets such as PUMP.
- Scanner labels tracked assets Active Research / Watchlist / Archived instead of offering Add to Research.
- Moving an asset between Active Research and Watchlist updates its Scanner lifecycle state and Highest-priority eligibility.
- Original curated origin does not force an asset onto Highest-priority Research.
