# Crypto Asymmetry Engine v9.0 — AI Research Engine v1

This patch is intentionally additive and must be applied to CURRENT GitHub `main`.
It does not replace the deterministic scoring engine.

## What v9.0 does
- Adds an authenticated `/api/ai-research` server endpoint.
- Sends a structured research packet to OpenAI.
- Stores each AI assessment in `ai_research_assessments`.
- Gives AI current quant state, up to 12 prior evaluations, matured 7D/30D/90D outcomes, position state, structure/regime context, and the prior AI assessment.
- Keeps AI observational. It cannot change Thesis Strength, Setup Evidence, Entry/Position labels, monitoring thresholds, or trades.
- Creates the dataset needed to later test whether AI adds value.

## Deployment
1. Copy `api/ai-research.js` into the repo.
2. Run `V9.0-MIGRATION.sql` in Supabase SQL Editor.
3. Append the same migration to the repo's `supabase.sql`.
4. Apply `FRONTEND-PATCH.txt` to CURRENT `src/main.jsx`.
5. In Vercel Production environment variables add:
   - `OPENAI_API_KEY` = your OpenAI API key
   - optional `OPENAI_MODEL` = `gpt-5.6-sol` (default)
6. Redeploy Production.

Never put `OPENAI_API_KEY` in a `VITE_` variable or in frontend code.

## Smoke test
Open a researched asset and press `Run AI research`.
Expected:
- request returns 200
- an AI Research Engine card appears
- one new row appears in `public.ai_research_assessments`

SQL:
select
  ra.symbol,
  ai.observed_at,
  ai.model,
  ai.stance,
  ai.confidence,
  ai.quant_ai_agreement,
  ai.summary
from public.ai_research_assessments ai
join public.research_assets ra on ra.id=ai.research_asset_id
order by ai.observed_at desc
limit 20;

## Historical-learning roadmap
v9.0 starts collecting AI judgments prospectively. Next phase should build a Historical Replay Engine that creates leakage-safe daily feature snapshots from historical market/fundamental data, computes 7D/30D/90D outcomes, and compares:
1. deterministic rules alone,
2. AI assessment alone,
3. agreement/disagreement cohorts.
Do not auto-tune thresholds until sample sizes are meaningful.
