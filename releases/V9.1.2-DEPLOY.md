# v9.1.2 — Sourced Research Timeout Fix

Current Vercel documentation (checked 2026-09-28) says Fluid-compute Vercel Functions default to 300 seconds on all plans, and Hobby supports a 300-second maximum. Pro/Enterprise can go higher.

This patch changes only `api/qualitative-research.js` from 60s to 300s.
`api/ai-research.js` stays at 60s because it has not demonstrated a timeout problem.

## Apply
Replace the current `vercel.json` with the included file and redeploy Production.

No Supabase migration.
No new environment variables.
No frontend change.
No score, signal, structure, monitoring, security, or AI prompt changes.

Existing v9.1.1 defensive JSON handling remains untouched.

## Smoke test
Open AAVE and run Sourced qualitative intelligence once.
If it succeeds, confirm the sourced panel appears and a `qualitative_research` row is stored.
Then refresh AI Research so the v9.1 AI assessment consumes the sourced evidence.

If a 300-second timeout still occurs, do not keep increasing the duration blindly. The next change should make the research job asynchronous/durable rather than holding a browser request open.
