# Multi-Year History Foundation
v9.3 adds `historical_price_daily` as the canonical provenance-aware long-history store.

Do not ask CoinGecko Demo for >365 days. For free multi-year expansion, the intended next adapter is Coinbase Exchange daily candles, paged across bounded time windows, but only after a verified Coinbase product ID is persisted for each asset. Do not map by ticker alone because symbol collisions exist.

Fallback order:
1. persisted Coinbase Exchange USD daily candles with verified product mapping;
2. paid CoinGecko historical range if later configured;
3. current CoinGecko Demo 365-day replay.

Record `source` and `source_symbol`; never silently splice sources.
