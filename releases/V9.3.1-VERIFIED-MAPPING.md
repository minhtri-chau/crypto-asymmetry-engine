# Verified Coinbase product mapping

v9.3.1 intentionally requires explicit mapping. Do not infer mappings inside the importer.

For each researched asset you want to backfill, verify the Coinbase Exchange USD product exists, then persist it:

```sql
update public.research_assets
set coinbase_product_id='AAVE-USD'
where symbol='AAVE' and coingecko_id='aave';

update public.research_assets
set coinbase_product_id='BTC-USD'
where symbol='BTC' and coingecko_id='bitcoin';
```

Use the Coinbase products endpoint / Coinbase listing evidence to verify each mapping. Do not bulk-update `symbol || '-USD'` without verification because ticker collisions and non-USD products exist.

The importer performs a second safety check against Coinbase's live USD product list before downloading any candles.
