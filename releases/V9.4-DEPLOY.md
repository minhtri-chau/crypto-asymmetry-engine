# v9.4 Calibration-Aware AI + Historical Analogs

## Purpose
v9.4 makes the existing AI Research Engine consume the validated multi-year empirical evidence without changing deterministic production scores.

Pipeline:
current quant + sourced qualitative intelligence + prior outcomes + empirical replay/calibration
→ AI Research assessment
→ stored assessment/input snapshot
→ future outcome validation

## Important interpretation
The calibration screenshot before this release already shows large cross-asset samples, including hundreds/thousands of 30D observations. These are overlapping weekly observations, so v9.4 explicitly forbids treating sample count as independent trials or turning cohort results into a probability/forecast.

## Deploy
1. Apply `patches/AI-RESEARCH-PATCH.md` to CURRENT `api/ai-research.js`.
2. Apply `patches/FRONTEND-PATCH.md` to CURRENT `src/main.jsx`.
3. No Supabase migration or Edge Function deployment is required.
4. Redeploy Vercel.
5. Open AAVE and run/refresh AI Research.

## Smoke test
The new stored AI assessment should contain:
- `historical_evidence_state`
- `historical_evidence_read`
- `historical_conflicts`

Its `input_snapshot.historical_evidence` should contain 7D/30D/90D asset and cross-asset calibration rows.

Verify:
```sql
select
 ra.symbol,
 ai.observed_at,
 ai.model_version,
 ai.stance,
 ai.confidence,
 ai.assessment->>'historical_evidence_state' as historical_state,
 ai.assessment->>'historical_evidence_read' as historical_read
from public.ai_research_assessments ai
join public.research_assets ra on ra.id=ai.research_asset_id
order by ai.observed_at desc
limit 10;
```

## What v9.4 intentionally does NOT do
- no automatic score/threshold tuning
- no expected-return target
- no probability of profit
- no AI-created historical facts
- no raw-candle prompt stuffing
- no regime backfill using today's regime
- no selection of cohorts because they have the highest historical return

The predefined v9.3 cohorts are passed as a complete set so the AI can see supportive and contradictory evidence.
